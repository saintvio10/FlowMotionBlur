Flow Motion Blur 2.2 - Plugin fuer Adobe Premiere Pro (macOS, Intel + Apple-Chip)
================================================================================

INSTALLIEREN (ohne Admin-Rechte)
1. Premiere Pro beenden.
2. Programm "Terminal" oeffnen und diese Zeile einfuegen (ZIP liegt in "Downloads"):

     cd ~/Downloads && rm -rf FlowMotionBlur_Mac && ditto -x -k FlowMotionBlur_Mac.zip . && mkdir -p ~/"Library/Application Support/Adobe/Common/Plug-ins/7.0/MediaCore" && rm -rf ~/"Library/Application Support/Adobe/Common/Plug-ins/7.0/MediaCore/FlowMotionBlur.plugin" && cp -R FlowMotionBlur_Mac/FlowMotionBlur.plugin ~/"Library/Application Support/Adobe/Common/Plug-ins/7.0/MediaCore/" && xattr -cr ~/"Library/Application Support/Adobe/Common/Plug-ins/7.0/MediaCore/FlowMotionBlur.plugin" && echo FERTIG

3. Premiere Pro starten -> Effekte -> "Flow Motion Blur".

BENUTZEN
- Effekt auf einen Clip oder eine Einstellungsebene ziehen, Staerke ueber
  "Blur Amount (Shutter)" (0.5 = Film-Look).
- Fuer schnelle Vorschau: "Analyse-Qualitaet" auf "Schnell".
- "Ansicht: Bewegungsvektoren" zeigt, was als Bewegung erkannt wird.
- "Premiere-GPU (Metal)": Bilder bleiben auf der Grafikkarte (schneller). Die Ansicht
  "Diagnose" zeigt in der Zeile "PREMIERE-GPU", ob dieser Weg aktiv war.
